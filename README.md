# 🌤️ Weather App

> 🚀 Built in under 6 hours with the help of AI (Claude) — from planning the features to writing the code, styling, and documentation.

A clean, responsive weather app built with **Next.js**, **TypeScript**, and **Tailwind CSS**. Search any city (or use your current location) to get real-time weather conditions and a 5-day forecast — with full dark mode and Arabic/English language support.

🔗 **Live demo:**([https://weather-app-lama15.vercel.app](https://weather-app-zeta-roan-79.vercel.app/))

---

## ✨ Features

- **City search** — look up weather for any city worldwide
- **Auto-location** — detects your current location on first load (with a fallback city if permission is denied)
- **5-day forecast** — daily high/low temperatures and conditions
- **Unit toggle** — switch between Celsius and Fahrenheit
- **Dark mode** — toggleable theme, saved across visits
- **Bilingual UI** — switch between English and Arabic (with full RTL layout support)
- **Live stats** — humidity, wind speed, and "feels like" temperature

## 🛠️ Built With

- [Next.js](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Open-Meteo API](https://open-meteo.com/) for weather and geocoding data

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/lamaabualhaj2/weather-app.git
cd weather-app
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.
